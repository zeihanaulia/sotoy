Ini file root untuk `The Developer's Guide to AI`. Isi di sini hanya preface/intro, lalu langsung diarahkan ke ringkasan per part. Detail chapter dan pembahasan teknis ada di file terpisah.

Buku ini disusun sebagai peta kerja developer yang bergerak dari model dasar ke sistem agent lengkap:

- Part I: Getting Started with AI
- Part II: Prompt Engineering
- Part III: Vector Databases and RAG
- Part IV: Adapting Models to Real-World Tasks
- Part V: Building Agentic Systems

Root ini berarti fokusnya pada konteks, target pembaca, dan alur besar buku.

## Mengapa struktur ini cocok

Buku ini tidak berusaha jadi referensi teori ML. Dia lebih membentuk peta praktis bagi developer yang pengin:

- pakai LLM tanpa harus jadi peneliti ML
- kontrol output lewat prompt dan kode
- tambahkan konteks dari data eksternal
- adaptasi model saat use case butuh
- bangun agent sebagai sistem yang bisa bertindak
