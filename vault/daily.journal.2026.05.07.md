## YouTube

Hari ini gue merangkum talk Andrej Karpathy “From Vibe Coding to Agentic Engineering” ke daily note. Fokusnya bukan lagi ke transkrip menit demi menit, tapi ke takeaway utama dan link ke note detail.

### Context
Gue baca talk ini dengan framing: **agentic engineering** adalah praktik engineering menggunakan agent AI, tapi tetap menjaga kualitas profesional lewat spec, verifikasi, oversight, dan desain sistem. Bukan sekadar “pakai AI buat coding cepat.”

Pembacaan ini juga penting karena talk April 2026 merefleksikan fase shift yang Karpathy lihat di akhir **Desember 2025**. Business Insider dan sumber lain menguatkan bahwa perasaan “behind as a programmer” serta pergeseran workflow ini muncul sebelum talk, bukan cuma sebagai framing di video.

### What I learned
- Vibe coding menaikkan floor: banyak orang bisa build software lebih cepat.
- Agentic engineering menjaga ceiling: pekerjaan profesional tetap harus secure, maintainable, testable, dan diawasi.
- Software 3.0 memindahkan programming dari menulis logika eksplisit ke mendesain prompt dan context yang dikonsumsi agent.
- Verifiability dan RL distribution menentukan di mana model paling kuat.
- Manusia masih jadi bottleneck understanding: kita masih harus tahu apa yang mau dibangun, kenapa, dan bagaimana mengarahkan agent.
