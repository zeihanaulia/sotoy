Prompt and context become source code in Software 3.0

Claim: Dalam Software 3.0, prompt dan context window berfungsi sebagai source code sementara yang digunakan untuk mengarahkan interpreter LLM.

Evidence:

  • Karpathy: "your programming now turns to prompting and what's in the context window is your lever over the interpreter that is the LLM."
  • Contoh OpenClaw: alih-alih shell script lintas platform, programmer menulis teks yang dicopy-paste ke agent.

Why it matters:

  • Menggeser fokus dari agar kode dapat dieksekusi menjadi agar instruksi dapat dipahami oleh model.
  • Menandai perubahan artifact engineering dari skrip ke prompt/runbook.
