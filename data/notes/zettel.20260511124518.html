Aplikasi engineering terbaik adalah paket sinyal, bukan dokumen tunggal

Lee Robinson thread menegaskan satu klaim atomik: aplikasi engineering modern bukan cuma dokumen tunggal, tapi paket sinyal.

Paket ini harus membuat reviewer cepat membaca:

  • CV sebagai ringkasan sinyal,
  • LinkedIn sebagai canonical reference,
  • GitHub sebagai bukti teknis,
  • website sebagai pembeda dan konteks tambahan.

Kalau salah satu elemen ini berantakan, sinyal keseluruhan melemah, walaupun elemen lain bagus.
