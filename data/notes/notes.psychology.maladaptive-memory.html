Maladaptive Memory vs Adaptive Learning

Maladaptive Memory vs Adaptive Learning

Core Concept

Pengalaman gagal seharusnya menjadi bahan update perilaku. Namun, pada maladaptive memory, kegagalan tidak menjadi pelajaran, melainkan menjadi bukti identitas.

Comparison of Processing Failure

Adaptive Learning (Data)Maladaptive Memory (Altar Penderitaan)
"Gue gagal ngomong →\rightarrow→ Gue perlu latihan struktur.""Gue gagal ngomong →\rightarrow→ Gue memang pengecut."
"Gue kalah kredit →\rightarrow→ Gue perlu nulis ide sebelum diskusi.""Orang lain dapat kredit →\rightarrow→ Dunia selalu nyuri dari gue."
"Gue malu →\rightarrow→ Gue perlu bangun toleransi rasa malu.""Gue malu →\rightarrow→ Gue sebaiknya diam saja."

Link to Neurotic Narcissism

Pola narsistik neurotik sering terjebak dalam maladaptive memory di mana luka lama membuat ego mengubah kegagalan menjadi narasi pusat: "Gue yang paling tidak dilihat." Jika narasi ini tidak diolah, ia menjadi identitas yang melumpuhkan aksi.

Atomic Idea: Kegagalan harus menjadi data, bukan menjadi altar penderitaan.
