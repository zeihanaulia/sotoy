## Why this reference matters

Awesome Skills code review skill bagus untuk struktur instruksi review yang lebih spesifik dan modular.

## What it teaches

- definisi review skill yang lebih granular,
- contoh checklist domain-specific,
- pendekatan progressive instruction.

## What to copy for our design

- pisahkan skill review berdasarkan domain,
- buat instruksi yang bisa dipanggil ulang,
- jangan satukan semua logika review di satu prompt besar.

## Gap vs our design

Ini fokus ke skill, belum ke GitLab integration atau comment flow.

## Practical takeaway

Gunakan sebagai template skill layer untuk security, performance, maintainability, dan authorisation review.
