Permanent repo instructions like AGENTS.md preserve agent behavior

Instruksi permanen seperti AGENTS.md atau CLAUDE.md membuat tuntunan agent terpisah dari prompt sementara. Ini penting agar perilaku agent mudah diperbaiki, diaudit, dan diwariskan di repo.
