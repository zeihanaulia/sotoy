Why this reference matters

What it teaches

  • AGENTS.md sebagai gateway overview,
  • load skill detail hanya ketika perlu,
  • ringkas overview, dalami detail hanya saat case demand.

What to copy for our design

  • gunakan AGENTS.md sebagai router skill,
  • hindari memuat seluruh rulebook ke satu prompt,
  • bagi review menjadi overview + detail skill load.

Gap vs our design

Ini sangat cocok untuk teaching review format, karena kita tidak perlu semua guideline dimasukkan sekaligus.

Practical takeaway

Desain review agent dengan overview file plus skill detail yang diambil on-demand.
