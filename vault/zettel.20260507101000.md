Claim: Dalam Software 3.0, programming tidak lagi hanya menulis kode eksplisit. Sebaliknya, prompt dan context window berfungsi sebagai source code sementara yang mengendalikan interpreter LLM.

Evidence:
- Karpathy: "your programming now turns to prompting and what's in the context window is your lever over the interpreter that is the LLM."
- Dia membandingkan Software 1.0 (kode eksplisit), Software 2.0 (dataset + neural network), dan Software 3.0 (prompt/context).

Why it matters:
- Mengubah cara kita memandang artifact engineering dari skrip menjadi instruksi kontekstual.
- Menegaskan bahwa nilai engineering di era agentic AI bergeser ke desain konteks dan instruksi, bukan hanya ke detail kode.
