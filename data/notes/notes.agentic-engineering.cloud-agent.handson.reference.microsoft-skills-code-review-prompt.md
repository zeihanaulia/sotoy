
## Why this reference matters

Microsoft Skills code-review prompt adalah contoh checklist yang eksplisit dan operasional untuk code review.

## What it teaches

- cara menulis guideline yang jelas,
- contoh fokus review untuk React/TypeScript,
- checklist yang bisa diubah jadi rule.

## What to copy for our design

- buat prompt/skill checklist yang eksplisit,
- jangan biarkan review output tetap vague,
- integrasikan aturan spesifik ke analogue skill.

## Gap vs our design

Ini bukan GitLab bot, namun sangat berguna untuk memperkuat skill layer.

## Practical takeaway

Ambil gaya prompt checklist ini untuk domain-specific review skill dan jadi basis rule-based suggestions.
