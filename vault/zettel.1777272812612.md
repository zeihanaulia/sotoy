## Ide inti

Prompt engineering hidup di bawah batasan context window; kapasitas terbatas memaksa kita memilih konteks dengan bijak.

## Quote baseline

> The context window is the amount of text that an LLM can process at once.

## Kenapa ini core

Ini membuka hubungan antara prompt assembly, cost, dan retrieval.
