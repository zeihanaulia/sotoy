Ide inti

Prompt butuh struktur dan kapasitas; mencampur semua hal akan menyebabkan model bingung dan request over limit.

Quote baseline

the LLM struggled to distinguish between articles and instructions. / The request size ... exceeded the limit.

Kenapa ini core

Ini membuka jalan ke prompt structure, context engineering, dan eventually RAG.
